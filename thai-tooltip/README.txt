OH Thai Tooltip (v0.1.0 ทดลอง)
================================
เอาเมาส์ชี้ที่ปืน เกราะ ม็อด Deviation หรืออาหารใน Once Human
แล้วจะมีกล่องแปลไทยขึ้นข้างกล่องรายละเอียดของเกม

วิธีทำงาน: อ่านภาพหน้าจอเท่านั้น (OCR) ไม่อ่านหน่วยความจำเกม ไม่แก้ไฟล์เกม ไม่กดปุ่มแทน
- เปิด/ปิด: Ctrl+Alt+T หรือคลิกไอคอน "ไทย" ที่มุมขวาล่าง Taskbar
- ทำงานเฉพาะตอนหน้าต่างเกม (ONCE_HUMAN.exe) อยู่ด้านหน้า
- เกมต้องเป็นโหมด Borderless/Windowed (Fullscreen แบบเต็มจอจะทับ overlay)
- ประโยคที่มีในคลัง (ขึ้นต้นด้วย •) แปลไว้ล่วงหน้าตามข้อความจริงในเกม
- ประโยคที่ยังไม่มีในคลัง (ขึ้นต้นด้วย ≈) แปลสำรองด้วย Google ปิดได้ในเมนูไอคอน
- ถ้าแปลไม่ขึ้น: เมนูไอคอน > "บันทึกภาพดีบัก" แล้วส่งไฟล์ในโฟลเดอร์ debug ให้แอดมิน

แก้คำแปลเอง: สร้างไฟล์ %APPDATA%\OHThaiTooltip\custom_th.json
  { "ประโยคอังกฤษเต็ม": "คำแปลไทย" }

สร้าง .exe ใหม่: ดับเบิลคลิก Build EXE.bat (ต้องมี Python 3.10+)
