OH Build Overlay (by MrSmitety Hub) — v0.1.0
เลือกบิ้วสาธารณะจาก hub.mrsmitety.com แล้วโชว์เป็นแถบโปร่งบนหน้าใส่ของในเกม Once Human
ชิ้นไหนใส่ตรงบิ้วแล้วจะขึ้นกรอบเขียว ✓ · ไม่ตรงขึ้นสีส้ม

หน้าที่รองรับ
- Weapons (กระเป๋าเลือกปืน): เช็คชื่อปืน + สไตล์ Calibration
- Armor (กระเป๋าเลือกเกราะ): เช็คชื่อชิ้น + หนังที่ใช้คราฟ
- Mod Backpack: เช็คชื่อ MOD + Suffix และขึ้นกรอบที่แถว MOD ที่บิ้วใช้
- Weapon Crafting: ชี้ใบ Calibration แล้วบอกว่าตรงบิ้วไหม ตัวเลือกอันดับเท่าไหร่ ค่าดีแค่ไหนในช่วง

ทำงานจากภาพหน้าจออย่างเดียว ไม่อ่านหน่วยความจำเกม ไม่แก้ไฟล์เกม ไม่ส่งปุ่มเข้าเกม
ต้องเปิดเกมแบบ Borderless หรือ Windowed (Fullscreen จริงจะไม่เห็นแถบ)
ซ่อน/แสดง: Ctrl+Alt+B · คลิกที่ช่องในแถบเพื่อติ๊กเองได้ · ลากแถบไปวางที่อื่นได้
สร้างไฟล์ .exe: ดับเบิลคลิก "Build EXE.bat" (ต้องมี Python)
