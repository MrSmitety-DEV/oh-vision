# OH-Vision Time Tracker

ตัวจับเวลา **Vision ⇄ ช่วงพัก** ลอยเหนือจอเกม Once Human จากช่อง MrSmitety

**ดาวน์โหลด:** [OH-Vision-Time-Tracker.exe](https://github.com/MrSmitety-DEV/oh-vision/raw/main/OH-Vision-Time-Tracker.exe) · เวอร์ชัน 1.2.0 · Windows 10/11

วิธีใช้และคำถามที่พบบ่อย: https://hub.mrsmitety.com/#oh-addons

1. ดับเบิลคลิกไฟล์ .exe (ไม่ต้องติดตั้ง)
2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway**
3. ตั้งเกมเป็นโหมดจอ Borderless หรือ Windowed

ปุ่มลัด: `Ctrl+Alt+V` ซ่อน/แสดง · `Ctrl+Alt+L` ล็อก (คลิกทะลุไปที่เกม)

## OH Thai Tooltip
ชี้ไอเทม (ปืน เกราะ ม็อด อาหาร) ใน Once Human แล้วขึ้นคำแปลไทยข้างกล่องรายละเอียด อ่านจากภาพหน้าจอเท่านั้น ไม่แตะไฟล์หรือหน่วยความจำเกม

**ดาวน์โหลด:** [OH-Thai-Tooltip.exe (เวอร์ชันล่าสุด)](https://github.com/MrSmitety-DEV/oh-vision/releases/latest/download/OH-Thai-Tooltip.exe)

- เปิด/ปิด: `Ctrl+Alt+T` หรือคลิกไอคอน "ไทย" ที่ Taskbar
- เกมต้องเป็นโหมด Borderless/Windowed
- ข้อมูลแปลอัปเดตอัตโนมัติจาก hub.mrsmitety.com

ซอร์สโค้ดอยู่ในโฟลเดอร์ `thai-tooltip/` ทุกครั้งที่อัปเดตโค้ด GitHub จะ build `.exe` ใหม่และออก Release ให้อัตโนมัติ

## OH Build Overlay
เลือกบิ้วจาก [hub.mrsmitety.com](https://hub.mrsmitety.com/#oh-builds) แล้วโชว์เป็นแถบโปร่งบนหน้า Gear ของ Once Human ชิ้นไหนใส่ตรงบิ้วแล้วขึ้น ✓ ชิ้นที่ยังขาดบอกว่าต้องใส่อะไร (ปืน · Calibration · เกราะ · หนัง · MOD + Suffix) อ่านจากภาพหน้าจอเท่านั้น

**ดาวน์โหลด:** ดูลิงก์ล่าสุดที่หน้า [Add-on](https://hub.mrsmitety.com/#oh-addons) หรือ [Releases](https://github.com/MrSmitety-DEV/oh-vision/releases) (tag `build-overlay-v…`)

- ซ่อน/แสดง: `Ctrl+Alt+B` · คลิกชื่อ MOD บนแถบ = คัดลอกไปค้นหาในเกม · คลิกขวา = ติ๊กเอง
- เกมต้องเป็นโหมด Borderless/Windowed · รองรับจอ 16:9

ซอร์สโค้ดอยู่ในโฟลเดอร์ `build-overlay/`
